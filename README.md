# 🎓 College Website (Multi-Page Frontend Project)

## 📌 About

This is a **multi-page college website frontend project** designed with a modern **dark theme UI**. It provides a structured layout for showcasing college information, departments, news, gallery, and contact details.

The project focuses on improving frontend development skills using **HTML and CSS** with clean navigation and responsive design.

---

## 🛠 Tech Stack

* HTML (78%)
* CSS (22%)

---

## 📄 Pages Included

* 🏠 `index.html` – Homepage / Landing page
* ℹ️ `about.html` – About the college
* 🏫 `departments.html` – Departments information
* 🖼️ `gallery.html` – Image gallery section
* 📰 `news.html` – Latest news listing page
* 🗞️ `news_page.html` – Individual news details page
* 📞 `contact.html` – Contact form and details

---

## 🎨 Styling

* `style.css` – Contains all styling rules
* Dark theme design for modern look
* Responsive layout structure

---

## ✨ Features

* 🌙 Modern dark theme UI
* 📱 Responsive design (mobile-friendly layout)
* 🧭 Multi-page navigation system
* 📰 News section with separate detail page
* 🖼️ Gallery section for visuals
* 📞 Contact page for communication
* 🎯 Clean and structured layout

---

## 🚀 How to Run

1. Clone or download the repository
2. Open `index.html` in any browser
3. Navigate through different pages using menu
